# Personal Notes

Notion 스타일의 개인 메모 웹앱입니다.

## 기능
- 페이지 생성 / 삭제
- 제목 및 본문 실시간 편집
- 브라우저 `localStorage` 자동 저장
- 메모 검색
- 다크 / 라이트 모드
- JSON 백업 내보내기
- 모바일 반응형 사이드바

## 데이터 저장 방식
메모 데이터는 서버나 GitHub 저장소가 아니라 **현재 사용하는 브라우저의 localStorage**에 저장됩니다.
따라서 브라우저 사이트 데이터를 삭제하거나 다른 PC/브라우저에서 접속하면 기존 메모가 자동으로 나타나지 않습니다. 중요한 메모는 `내보내기` 버튼으로 백업하세요.
